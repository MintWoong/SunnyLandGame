SunnyLand Game
Một game 2D đi cảnh đơn giản được phát triển bằng Unity2D và ngôn ngữ C# – sản phẩm thực hành của sinh viên ngành Kỹ thuật phần mềm.

🎮 Giới thiệu
SunnyLand Game là trò chơi 2D thể loại platformer nơi người chơi điều khiển một nhân vật vượt qua các chướng ngại vật, thu thập vật phẩm và hoàn thành màn chơi.

Dự án được thực hiện nhằm:

Làm quen với công cụ Unity

Luyện tập lập trình game bằng ngôn ngữ C#

Thiết kế animation, xử lý va chạm và điều khiển nhân vật cơ bản

⚙️ Công nghệ sử dụng
Công nghệ	Mục đích
Unity2D	Phát triển và dựng cảnh game
C#	Viết script điều khiển nhân vật, logic gameplay
Unity Animator	Tạo chuyển động nhân vật
Tilemap	Thiết kế bản đồ, môi trường

✨ Tính năng chính
Di chuyển trái/phải, nhảy (jump)

Va chạm vật thể, rơi từ độ cao

Thu thập đồng xu (coin)

Hệ thống animation mượt mà

Giao diện hoạt hình dễ thương (asset từ Unity Asset Store)
